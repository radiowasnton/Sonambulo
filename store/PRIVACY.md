# Privacy Policy — Sonámbulo

Sonámbulo does not collect, transmit, sell or share any personal data.

- Your settings and the list of websites you customize are stored locally in your browser (`storage.local`) and never leave your device.
- The extension runs no remote code and sends nothing anywhere. Its only network requests fetch the stylesheets of the page you are visiting (the same files the page already loads), so they can be recolored locally.
- It reads the address of the page you are visiting only to apply the mode you chose for that site. That information is not stored beyond the host names you explicitly customize.
